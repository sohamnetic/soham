Privacy Policy

Placement Reminder · Last updated: 24 September 2026

Data the app accesses

With the user's permission, the app uses the Gmail API with read-only access (gmail.readonly) to read emails in the user's own mailbox. It cannot send, delete or change any email.

How the data is used

Emails are scanned only to find placement drive announcements and replies from companies the user has applied to. From those emails the app extracts the company name, pay details, eligibility criteria, registration deadline and a short preview, and sends reminders to the user's own Telegram account.

Storage and sharing

  • The app runs on the user's own computer. Extracted details are stored in a local database on that computer only.
  • Reminder messages are delivered through Telegram to the user's own chat. No other person or service receives the data.
  • Data is not sold, shared, used for advertising, or used to train AI models.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local folder removes all stored data.
